# README.md

> 前情提要：在阅读这篇伟大的小作文时，你必须时刻认识到，你阅读的每一个字都是由AI生成的,并且所有情节都是虚构，如有雷同纯属巧合！

我们伟大的马克思同志，曾经在他的鸿篇巨制的《资本论》中留下过一句话：

> 「一切现实的危机的最终原因，总是群众的贫穷和他们的消费受到限制，而与此相对比的是，资本主义生产竭力发展生产力，好像只有社会的绝对的消费能力才是生产力发展的界限。」

后来历史花了相当长的时间，十分耐心地向我们证明：**他说得对。**

而且为了避免后人怀疑这是巧合，历史甚至贴心地送来了 **1929 年的大萧条**。

彼时的生产力正在以一种令人感动的速度飞驰，机器越来越先进，流水线越来越高效，企业越来越懂得如何把一个工人的时间切割成更加精细的时间单位。于是，一个极其优美的经济学现象出现了：**工人生产得越来越多，工人的钱包却没有以同样的速度变得丰满。**

多么和谐。**资本负责不断扩大生产，劳动者负责不断承担消费能力不足的后果。**前者创造「繁荣」。后者负责「理性消费」。实在是一套堪称完美的闭环。

## 中国特色的“劳动热爱”

进入新时代以后，我们惊喜地发现，这套古老的逻辑并没有消失。它只是学会了说一些更加文明、更加温柔、更加积极向上的词。

例如：「奋斗。」「奉献。」「主人翁精神。」「狼性文化。」「吃苦耐劳。」「降本增效。」

以及最经典的：**“年轻人吃点苦没什么。”**

当然没什么，毕竟年轻人拥有全世界最优秀的一种生产资料：**年轻人自己。**只要还年轻，就可以被安排加班；只要还能加班，就可以继续“锻炼”；只要还能继续“锻炼”，就说明企业管理得非常成功。至于劳动者为什么越来越疲惫、为什么越来越想离开、为什么越来越不愿意消费——这一定是年轻人的心态出了问题。**绝不可能是生产关系出了问题。**

比如被人民所热爱的富某某工厂。它规模庞大，设备先进，生产体系高度标准化，管理流程精确而完整，正如它名字中的那个「富」字一样，仿佛象征着「劳动人民的富裕」。只不过，后来发生了那么一点小小的意外。当然，也不是什么大事情。我们伟大的富某工厂也随即进行了一系列所谓的「改革」：对流水线进行了「大改」，对所谓的薪资待遇进行了「提高」。当然，它所发生的事件，也顺带促进了国内某些同样十分具有责任心的工厂进行「改革」。而在这一轮轰轰烈烈的改革过程中，企业也创造出了一批极具人文关怀色彩的新词汇。不得不说，**现代管理学最显著的进步之一，就是越来越擅长给现实配置一套温和、专业、充满关怀意味的词汇。**

到了 2026 年，这套成熟的管理语言也迎来了新的实践机会。星某企业在校招阶段吸纳了新一届毕业生，随后进行了「岗位优化」。至于那 107 个人，在我看来，他们的表现多少有些不够体谅企业。毕竟企业经营也是很不容易的，企业存在的意义终究是创造利润，没有利润，企业便难以生存。在这样的关键时刻，他们非但没有展现出应有的奉献精神，反而对公司的安排产生了些许意见，实在令人遗憾。

首先，他们是“2026 届毕业生”；随后，他们成为“入职员工”；接着，他们进入“岗位优化名单”；最后，他们正式成为“解除劳动合同人员”。

**多么成熟而高效的一套管理流程！**从人才引进，到人员配置，再到优化退出，每一个环节都衔接得如此自然、如此流畅。想来这样的决定，公司应该也不是第一次作出；如此娴熟的流程，自然值得继续保留。毕竟，对于一家现代化企业而言，能够如此熟练地完成人员的进入与退出，本身就是一种难得的管理经验。至于那些应届毕业生后来对此表现出了些许不满，甚至做出了某些“过分”的举动，那倒也就不足为奇了。毕竟，他们大概还需要一点时间，才能充分理解这套先进管理体系的深刻内涵。

---

值得庆幸的是，人类文明已经发展到了一个非常先进的阶段。

我们甚至发明了一种神奇的东西：**法律。**

根据《国务院关于职工工作时间的规定》，职工每日工作 8 小时、每周工作 40 小时；相关规定同时明确，任何单位和个人不得擅自延长职工工作时间。《劳动法》还规定，用人单位应保证劳动者每周至少休息一日。

而当工作确实需要延长时——**法律甚至大方地允许企业用钱来表示自己的歉意。**

| 伟大的企业行为      | 伟大的法律补偿      |
| ------------ | ------------ |
| 工作日延长工作时间    | ≥ 正常工资的 150% |
| 休息日工作且不能安排补休 | ≥ 正常工资的 200% |
| 法定节假日工作      | ≥ 正常工资的 300% |

上述加班工资标准来自《劳动法》第四十四条。

看，法律多么温柔。它甚至考虑到了这样一种情况：**企业可能会非常非常想让你留下来。**所以法律提前替你准备好了价格。

## 当然，我们不能要求所有企业都读法律

这未免太苛刻了。毕竟企业每天已经很忙了。要研究市场。要研究竞争对手。要研究 AI。要研究降本增效。要研究怎么把一百个人的工作交给八十个人做，再把剩下二十个人的工作交给这八十个人。哪里还有时间研究什么《劳动法》？更何况，有些企业确实非常重视法律。

例如：只要劳动者愿意签字，一切就都可以被重新解释。于是“自愿加班”诞生了。“自愿调岗”诞生了。“自愿离职”诞生了。“自愿奋斗至深夜”诞生了。甚至连“公司建议”也开始表现出一种惊人的自愿性。

这充分说明：**自由，真是一个伟大的东西。**尤其当你拥有“不同意之后会发生什么”的自由想象时。

## 这就是本项目存在的意义

我们当然不能指望资本突然顿悟。

毕竟要求一个以利润为核心指标的组织突然把劳动者利益置于利润之上，就像要求余额不足的银行卡突然开始慈善一样。这不是道德问题。这是功能没实现。所以，我们决定做一件更加朴素的事情：**记录。**

记录哪些地方真正实行双休。
记录哪些地方名义双休，实际需要“带一点工作回家”。
记录哪些企业把“弹性工作制”理解成：**工作时间富有弹性，员工的休息时间没有。**
记录企业实际工作时长。
记录加班情况。
记录是否存在长期超时工作。
记录学校究竟有没有真正意义上的双休。

以及一些更加具有「中国特色」的校园现象：

* 是否强制早自习；
* 是否强制晚自习；
* 周末是否存在变相补课；
* 是否存在不合理限制异性社交,禁止异性之间产生好感的规定；
* 是否存在强制统一发型、服饰等管理要求；
* 以及其他值得被公众知道的管理措施。

我们不会替任何企业、学校提前判刑。我们也不会替任何劳动者、学生提前下结论。**我们只是把现实摆在那里。**至于一个企业到底是不是“良心企业”，一个学校到底是不是“人性化管理”——这个问题，就交给真正生活在那里的人来回答。

## 为什么要公开？

因为有一些东西，一旦进入公开记录，就会变得非常有趣。

例如：

> “我们非常重视员工休息。”
> **很好。那么实际双休吗？**

> “我们严格遵守劳动法律法规。”
> **很好。那么每周实际工作多少小时？**

> “我们坚持以人为本。”
> **很好。那么晚上几点下班？**

> “我们的学生身心健康发展是第一位的。”
> **很好。那么为什么周末还有课？**

你看，**数据真是一种非常没有礼貌的东西**，它不懂察言观色，不会因为一句“企业文化”就自动变绿，也不会因为一句“为了学生未来”就自动把 7×24 小时重新命名为“全面发展”。

## 我们并不反对努力

恰恰相反。

真正值得被反对的，从来不是劳动，也不是奋斗。

而是把：**违法的超时劳动包装成奋斗，把不合理的管理包装成培养，把单方面牺牲包装成企业文化，再把劳动者的沉默包装成认同。**

一个人愿意努力，是他的选择。一个人被迫长期透支，却被告知：“大家都是这么过来的。”**这就是另一回事了。**

## 最后

我们当然希望有一天，这个项目会变得毫无意义。

希望某一天，再也没有企业需要被记录“双休还是单休”。

希望再也没有人需要专门调查：“你们到底几点下班？”

希望“依法休息”不再是一种需要勇气争取的特殊待遇。

希望学校不需要被提醒：“学生也是人。”

希望企业不需要被提醒：“员工也是人。”

更希望有一天，我们甚至不必建立这样的数据库。

因为那意味着：**现实终于追上了法律。**

在那一天到来以前，

我们姑且继续做一件非常危险的事情：**如实记录，不煽动，不美化。**不替任何人歌功颂德。也不负责让某些漂亮的报表变得更漂亮。我们只负责保存事实。因为有时候，真正让某些人感到不舒服的，并不是批评，而是**有人开始认真记录了。**

## ⭐ 星星之火，可以燎原

一个人的记录，也许只是一个数字。十个人的记录，也许只是一个表格。一千个人的记录，也许就是一张地图。

而当足够多的人开始认真回答：

> **“我所在的地方，到底是怎么工作的？”**

那么我们或许终于可以知道：**究竟是谁在遵守规则，谁在解释规则，谁在利用规则的沉默。**

欢迎提交你所知道的真实情况。

让我们一起建设这份并不怎么讨企业管理者喜欢、但劳动人民或许会喜欢的数据库。

毕竟——**法律已经写在那里了。**

现在唯一缺的，可能只是有人提醒大家：

> **“哦，原来真的可以这样。”**

---

我国已经为中小学生的睡眠、作息和休息建立了相当完整的制度要求。

令人欣慰的是，这些规定如此完善，以至于教育部门需要不断提醒学校：**不要让学生在周末上课，不要让学生长期超长学习，不要挤占睡眠时间。**

我们对此深表欣慰。

毕竟，一个规定已经明确了很多年的“不能做的事情”，如果还需要不断发布典型案例提醒大家不要做，至少说明这项规定拥有**极其旺盛的生命力。**
